Aviso en línea para resultados de una corrida o validaciones previas. `error` cuando la corrida falló o un informe no tiene marcadores cableados; `warning` para corte por tiempo o datos parciales; `info` para contexto neutro (de dónde sale un valor por defecto).

```jsx
<Alert kind="error" title="No se generó.">La cadena de período no resuelve.</Alert>
<Alert kind="warning">Corte por tiempo en la etapa de secciones a los 340 s.</Alert>
```
